POS Dashboard & Reporting Suite

Dashboard & 16 laporan Point of Sale — ringan, dengan grafik interaktif dan export Excel/PDF

Fitur Utama

  • Dashboard interaktif — ganti laporan, rentang tanggal, POS, dan kasir dari satu layar, dengan grafik Chart.js.
  • 16 laporan siap pakai — order, penjualan, pajak, per kasir, per kategori/tenant/rides/bracelet/ticket, akuntansi, hingga ringkasan direksi.
  • Export Excel & PDF untuk semua laporan, memakai query yang sama persis dengan yang tampil di layar.
  • Mapping kategori — tandai kategori produk sebagai Tenant / Rides / Bracelet / Ticket / Bundling tanpa perlu field custom baru.
  • Ringan — seluruh angka dihitung dengan SQL agregat (SUM/GROUP BY) yang difilter tanggal & company, bukan membaca seluruh tabel transaksi.
  • 2 level akses — Dashboard User (lihat & export) dan Dashboard Manager (+ atur mapping kategori).

Catatan Setelah Instalasi

Buka menu POS Dashboard > Konfigurasi > Mapping Kategori Laporan dan petakan kategori produk Anda ke tipe Tenant / Rides / Bracelet / Ticket / Bundling agar laporan-laporan terkait langsung terisi data.
